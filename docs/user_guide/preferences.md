# Preferences

Opened via **File → Preferences...**. Settings persist between sessions.

| Setting | Default | Controls |
|---|---|---|
| Auto-adjust quality for large tilings | On | Automatically lowers antialiasing for large tilings to <br> keep the app responsive. Turn off to always render <br>at full quality regardless of size. |
| Reduce MSAA above (est. tiles) | 6000 | Tile-count threshold above which rendering drops<br> from high to medium antialiasing. |
| Disable AA + MSAA above | 10000 | Tile-count threshold above which antialiasing is <br>switched off entirely. |
| Show Advanced window on startup | Off | Opens the Advanced Settings dock automatically<br> when HyperTiler launches. |
| Colouring | Colour <br>theory | Choose between tiles generated using colour<br> theory matching, or tonal based on a colour<br> swatch.|

`Reset to defaults` restores all preferences above; `OK` saves your
changes, `Cancel` discards them.
